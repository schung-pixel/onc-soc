# 항암 표준요법 (Oncology SoC)

암종별 표준요법, NCCN 대조 상태, 근거 임상, 진행 중·주목 임상을 정리한 개인 참고용 웹앱(PWA)입니다.

- 휴대폰 브라우저로 열고 "홈 화면에 추가"(Android Chrome: 메뉴 → 앱 설치)하면 앱처럼 실행됩니다.
- 한 번 열면 오프라인에서도 볼 수 있습니다. 새 버전이 올라오면 상단에 새로고침 안내가 뜹니다.
- 임상 판단이나 제출 자료의 근거는 반드시 NCCN 원문(NCCN.org)과 원 논문으로 확인하십시오. NCCN Guidelines®는 National Comprehensive Cancer Network, Inc.의 등록 상표이며, 이 앱은 NCCN이 작성·검수·승인한 자료가 아닙니다.
